# 🎵 Spotify Downloader

A simple and modern Spotify Music Downloader with a clean glassmorphism interface.

## Features

- 🎵 Search Spotify tracks
- 🖼️ Album artwork preview
- 👤 Artist information
- ⏱️ Track duration
- 🎧 MP3 download
- ⚡ Fast performance
- 📱 Responsive design
- ✨ Modern UI
- ❌ Error handling
- 🔄 Loading animation

## Getting Started

1. Clone the repository.

```bash
git clone https://github.com/providerbotz/SpotifyDownload.git
```

2. Open `index.html` in your browser.

3. Paste a Spotify track URL.

4. Click **Search Track**.

5. Download your MP3.
